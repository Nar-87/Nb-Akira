# NB-Akira ⌚

NB-Akira es una tienda online ficticia especializada en relojes de lujo y accesorios premium. El proyecto ha sido desarrollado como una aplicación web estática utilizando HTML5, CSS3 y Bootstrap 5, con un enfoque en el diseño responsive, la experiencia de usuario y la organización de contenido propia de un comercio electrónico.

## Demo Online

https://nar-87.github.io/Nb-Akira/

## Descripción

NB-Akira simula una plataforma de comercio electrónico donde los usuarios pueden explorar diferentes categorías de relojes, consultar productos destacados, acceder a promociones, gestionar un carrito de compra visual y obtener información adicional mediante páginas de contacto, preguntas frecuentes y secciones corporativas.

El proyecto ha sido diseñado siguiendo una estética elegante basada en tonos negros, blancos y dorados para transmitir una imagen de exclusividad y sofisticación.

---

## Funcionalidades

* Página principal con presentación visual de la marca.
* Menú de navegación responsive.
* Catálogo organizado por categorías.
* Fichas de producto con imágenes y detalles.
* Carrito de compra visual.
* Página de cuenta de usuario.
* Sección de ofertas y promociones.
* Temporizador para campañas promocionales.
* Página de preguntas frecuentes (FAQ).
* Página de contacto.
* Página corporativa "Nosotros".
* Integración visual de redes sociales.
* Diseño adaptable a dispositivos móviles y escritorio.

## Diseño Responsive

La aplicación ha sido desarrollada siguiendo principios de diseño responsive para garantizar una correcta visualización en:

* Ordenadores de escritorio.
* Tablets.
* Dispositivos móviles.

Bootstrap 5 se ha utilizado como framework principal para la maquetación y adaptación de los distintos componentes de la interfaz.
